Sobre
Overlay para a live do MMMV — mostra um drone 3D acompanhando a Renault Master ao longo da viagem.

Em Mock, a van anda numa rota fake da BR-101 SC a 50 km/h. Em API Produção, ela mostra a posição GPS real reportada pelo celular do motorista (poll a cada 60s via www.mmmv.com.br/api/location).

Use no OBS como Browser Source 1920×1080. Pressione H antes de gravar pra ocultar este menu.

OBS dica: use a URL mapa-3d-van.html?source=api pra forçar a fonte sem precisar do menu (override do localStorage).

Deploy: Mapbox token configurado já é público (pk.…). Antes de subir pro GitHub Pages, restrinja-o por URL no painel Mapbox pro seu domínio *.github.io/*.
